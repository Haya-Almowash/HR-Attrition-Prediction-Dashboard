# HR Attrition Prediction Dashboard

This project analyzes employee attrition patterns using Power BI and machine learning techniques.

## Project Overview
The goal of this project is to help HR teams understand the main factors behind employee attrition and support better decision-making.

## Tools Used
- Power BI
- Python
- Pandas
- Scikit-learn
- Machine Learning

## Key Insights
- Overtime increases attrition risk
- R&D department has the highest attrition rate
- Prediction Accuracy: 86%

## Project Files
- Dashboard → Power BI dashboard file
- Python → Machine learning notebook
- Images → Dashboard preview images
- Dataset → HR dataset used in the project
